# First Machine Learning Classifier

## Project Overview
This project implements a Decision Tree Classifier using Scikit-Learn and the Iris dataset.

## Key Features
- Train/Test data splitting
- Decision Tree model training
- Prediction using Scikit-Learn
- Accuracy evaluation
- Confusion Matrix
- Classification Report

## Tools Used
- Python
- Pandas
- Scikit-Learn
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Dataset
Iris Dataset from Scikit-Learn.

## Expected Outcome
The project demonstrates a basic supervised machine learning pipeline, including data preparation, model training, prediction, and performance evaluation.
